# Design

## Goal

A 5250 terminal emulator that opens as a VS Code editor tab, behaves like IBM i
Access Client Solutions (ACS) for day-to-day work, and installs with nothing
else: no Java, no Node, no packages on the IBM i.

## Shape

```
extension host (Node, bundled with VS Code)        webview tab (canvas)
  src/extension/   commands, panels, settings  <->   src/webview/  renderer,
  src/host/        sockets (net / tls)          msgs  keymap, OIA, selection
  src/engine/      pure TN5250 protocol: no vscode, DOM or Node imports
  src/shared/      message types between host and webview
```

- The **engine** is deterministic: bytes in, screen model and bytes out. It is
  tested with recorded data streams (`test/fixtures`) and synthetic streams.
  `tsconfig.engine.json` compiles it with no DOM or Node libraries so it stays
  portable.
- The **webview** only renders snapshots and turns physical keys into named
  5250 actions through a keymap. Field editing rules live in the engine.
- **No runtime dependencies.** Everything is bundled by esbuild into two files.

## Keyboard capture

VS Code forwards key events from a webview to its keybinding service, so a
focused terminal would still trigger F1 (Command Palette), F5 (debug), F11
(full screen) and so on. Two measures:

1. The webview handles every terminal key with `preventDefault()`.
2. `package.json` binds those same keys to the no-op command `tn5250.shadowKey`
   with `when: activeWebviewPanelId == 'tn5250.terminal'`, generated by
   `scripts/gen-keybindings.mjs`.

Keys that keep their VS Code meaning while the terminal is focused are listed
in `src/webview/keyboard.ts` (`isPassThrough`): Command Palette, Quick Open,
editor switching, sidebar and panel toggles, chords, window close.

Manual check for this design (run from an Extension Development Host with
**TN5250: Toggle Key Debug Overlay** on): F1, F5, F11, F12, Escape, Tab,
PageUp/PageDown, Home, Insert, Ctrl+A must show "-> terminal" in the overlay
with no VS Code reaction; Ctrl+Shift+P and Ctrl+Tab must show "-> VS Code"
and work normally.

## Sizing

The renderer scales the font so the full 24x80 or 27x132 grid fits the tab
(`tn5250.appearance.autoFit`). Ctrl+wheel, Ctrl+=, Ctrl+- zoom relative to the
fitted size and Ctrl+0 resets; the viewport scrolls when zoomed past the tab.

## Security

- Passwords are never stored; the sign-on screen is the authentication.
- TLS is a per-profile option (`tls: true`, port 992). Certificates are
  validated; untrusted ones prompt before the first connection.
- The webview runs with a strict Content Security Policy and only loads the
  extension's own bundled script and stylesheet.
